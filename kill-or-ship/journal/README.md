# Journal. 영속 메모리

이 디렉토리는 스킬의 영속 메모리다.
세션마다 여기에 학습이 누적되고, 이 누적이 다음 세션의 첫 입력이 된다.

---

## 파일 구성

| 파일 | 무엇을 담는가 |
|---|---|
| `cases.md` | 받은 케이스, 진단, 피드백 요지, 제시한 행동 |
| `reflections.md` | 자기 비판 (놓친 것, 과대 단정, 톤 점검, 패턴 매칭) |
| `evolution.md` | 스킬 자체 수정 이력 (수정 파일, 사유, 변경 내용) |

---

## 작성 규칙

### 1. 덮어쓰기 금지

모든 기록은 **추가만** 한다. 과거 기록을 수정하거나 삭제하지 않는다.
틀린 기록도 그대로 둔다. 그게 학습의 일부다.

### 2. 매 세션 기록

세션마다 최소한 `cases.md` 와 `reflections.md` 에는 기록한다.
`evolution.md` 는 실제 스킬 수정이 일어났을 때만.

### 3. 짧게 기록

각 항목은 5줄 이내. 길게 쓰면 누적될수록 읽기 부담이 커진다.

### 4. 패턴 추적

`reflections.md` 에서 같은 종류의 "놓친 것" 이 반복되면 `evolution.md` 에서 스킬 수정 트리거가 된다.

---

## 자기 진화 사이클

```
세션 N:
  1. cases.md, reflections.md, evolution.md 읽기
  2. 케이스 처리
  3. cases.md 에 기록 추가
  4. reflections.md 에 자기비판 추가
  5. 패턴이 누적되면 evolution.md 에 스킬 수정 기록
     실제로 references/ 또는 SKILL.md 수정

세션 N+1:
  1. (업데이트된) 모든 저널 다시 읽기
  2. 다음 케이스 처리
  ...
```

이번 출력이 다음 입력의 일부가 되고, 스킬 자체가 진화한다.
